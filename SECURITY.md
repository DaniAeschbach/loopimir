# Security

Please report security problems privately: **Security → Report a vulnerability** on this repository.

Loopimir is meant for your **own network**. Do not expose port 8090 to the internet (use a VPN such as Tailscale) and set a page password in *Settings*. Printer access codes are stored in `~/.local/share/loopimir/config.json` (permission `600`) — keep that folder private, and never post codes or serial numbers in issues.

Only the newest release receives fixes — keep Loopimir updated (*Settings → Updates*).
